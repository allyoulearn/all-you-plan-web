# All You Plan — Sub-project 3: Chores — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build the Chores screen on web and mobile, wired live to the `chores` GraphQL API.

**Architecture:** Mirrors the SP2 Today screen exactly — new Apollo operations + a `chores` store + compound components + the screen, all on the existing Foundation primitives and the live API.

**Tech Stack:** web — Vue 3 / Pinia / Apollo / Vitest; mobile — Expo / RN / Zustand / Apollo / TypeScript.

**API contract** (already built — see `2026-05-21-sp2-api.md` Task 5): `chores` query → `[Chore { id, title, cadence { type daysOfWeek interval dayOfMonth }, streak, bestStreak, lastCompletedOn, active, order }]`; mutations `completeChore(id, date)`, `createChore`, `updateChore`, `deleteChore`.

**Design reference:** the Claude Design bundle — desktop `screens.jsx` Chores screen ("Small habits, *kept.*", chores grouped Daily / Weekly / Monthly, each row showing cadence + streak); mobile `mobile.jsx` `MChoresScreen` (a daily/weekly/monthly segmented control, chore cards with a large check, title, "cadence · last done" meta, and a streak progress bar).

This sub-project is UI-only. Both apps' `chores` route is currently a Foundation placeholder. Work directly on `main` in each repo, one commit per task.

## Notes & verification

- The "completed today" state of a chore: `chore.lastCompletedOn` (an ISO date string) falls on the current local day. Implement a small shared helper inline in each store/component as needed.
- `createChore`/`updateChore`/`deleteChore` exist in the API but the design's Chores screen has no create/edit UI in scope here — the "New chore" button renders (Foundation `Button`) but needs no handler this sub-project.
- End-to-end check (deferred if no API/DB running): with the seeded API up, the Chores screen shows the seeded chores grouped/segmented by cadence, and completing one updates its streak.
